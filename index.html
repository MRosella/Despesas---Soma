          Configurações

          Sincronização entre dispositivos

          Sincroniza seus lançamentos com um repositório privado no GitHub, para abrir os mesmos dados no celular e no computador.

          O token fica salvo apenas neste aparelho. Use um token fine-grained com permissão de Contents: Read and write só nesse repositório.

          Não configurado.

          Bloqueio do app

          Protege seus dados (CPF, conta, token) caso o aparelho seja perdido. Pede autenticação ao abrir o app.

          Bloqueio desativado.

          Comprovantes (Google Drive)

          Anexe a foto do cupom em cada lançamento. As imagens são guardadas no seu Google Drive, em uma pasta separada por relatório (“Comprovantes - Despesas Soma”, “Comprovantes Cartao Santander - Despesas Soma” e “Comprovantes - SA Ambiental”), que você pode mover para onde quiser. Elas entram como páginas finais do PDF.

          Crie no Google Cloud (tipo “Aplicativo da Web”, origem https://mrosella.github.io). Funciona só no site publicado (HTTPS).

          Preenchendo, a conexão com o Google passa a durar indefinidamente (não pede login de novo a cada ~1h/dia). Sem isso, o app funciona igual, mas pode pedir login com mais frequência.

          No mesmo projeto do Client ID: “APIs e serviços → Credenciais → Criar chave de API” (ative a Google Picker API) e o número do projeto fica no painel inicial. Servem só para abrir o seletor de pastas — a permissão do app continua restrita ao que ele cria e ao que você escolher.

          Pastas dos relatórios

          Cada relatório grava numa pasta própria. Use Escolher pasta para apontar o relatório a qualquer pasta já existente do seu Drive — a partir daí os comprovantes vão para lá, em subpastas Ano/Mês. Sem escolher, o app cria a pasta padrão na raiz do Drive (e você pode movê-la depois: o app guarda o identificador, não o caminho).

          O botão Procurar comprovantes no Drive fica na tela de Lançamentos. Ele reconhece arquivos subidos manualmente à pasta (pede permissão de leitura na 1ª vez e usa a IA).

          Não configurado.

          Leitura de comprovante (IA)

          Ao anexar a foto do cupom/NF, o app lê a nota e preenche automaticamente valor, data, categoria e descrição, além de nomear o arquivo no Drive como NF nº data. Usa a API Google Gemini com uma chave sua (do Google AI Studio), guardada só neste aparelho. Há camada gratuita; acima dela o custo é de centavos por foto.

          Gere em aistudio.google.com → “Get API key”. Funciona só no site publicado (HTTPS).

          Não configurado.

          Categorias e limites

          Edite as categorias de despesa e o teto de reembolso de cada uma (deixe vazio/0 para sem limite). Vale para o seletor de lançamentos, os avisos de limite, o rodapé do PDF e a leitura automática do comprovante. Renomear uma categoria não altera lançamentos já salvos.

          Backup / Restaurar

          Salva um arquivo .json com todos os dados (atuais e histórico) como rede de segurança, independente da nuvem. Se a sincronização estiver configurada, também grava uma cópia versionada no Git.
